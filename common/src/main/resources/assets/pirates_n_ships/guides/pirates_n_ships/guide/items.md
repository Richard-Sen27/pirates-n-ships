| <ItemLink id="pirates_n_ships:rapier" /> | 2 iron ingots, 1 stick | Sword. See [Weapons](combat.md). |
| <ItemLink id="pirates_n_ships:cutlass" /> | 3 iron ingots, 1 stick | Sword. |
| <ItemLink id="pirates_n_ships:saber" /> | 2 iron ingots, 1 gold ingot, 1 stick | Sword. |
| <ItemLink id="pirates_n_ships:pistol" /> | 2 iron ingots, 1 flint, 1 planks | Single-shot flintlock: load with lead shot and gunpowder, fire. See [Firearms](combat.md#firearms). |
| <ItemLink id="pirates_n_ships:musket" /> | 2 iron ingots, 1 flint, 1 planks | Longer reload, flatter and tighter shot. See [Firearms](combat.md#firearms). |
| <ItemLink id="pirates_n_ships:lead_shot" /> | 2 iron nuggets (gives 4) | Ammunition for pistol and musket, one per load, with one gunpowder. |
| <ItemLink id="pirates_n_ships:cannonball" /> | 4 iron ingots (gives 2) | Ammunition for the cannon, loaded after the gunpowder. |
| <ItemLink id="pirates_n_ships:grappling_hook" /> | 3 iron ingots, 1 string | Throw it at another ship to hook it and haul the hulls together. See [Grappling hook](combat.md#grappling-hook). |
| <ItemLink id="pirates_n_ships:rope" /> | string | Use it on a cleat or mooring ring, then on a second one up to 16 blocks away on the same ship: a stay (2+ blocks lower, cleats only) or a decorative rope line. It glints while it remembers the first anchor. |
| <ItemLink id="pirates_n_ships:hull_patch" /> | 2 planks, 1 coal or charcoal (gives 2) | Use on the edge of a hole in an assembled hull to close the breach. See [Fighting a leak](ships.md#fighting-a-leak). |
| <ItemLink id="pirates_n_ships:doubloon" /> | none | Currency. |
| <ItemLink id="pirates_n_ships:tobacco" /> | none | Trade good. |
| <ItemLink id="pirates_n_ships:spices" /> | none | Trade good. |
| <ItemLink id="pirates_n_ships:cloth" /> | 3 string | Trade good. |
| <ItemLink id="pirates_n_ships:rum" /> | 1 sugar cane, 2 sugar, 1 glass bottle | Trade good and provision. Drinkable, leaves a bottle. |
| <ItemLink id="pirates_n_ships:hardtack" /> | 3 wheat, 1 water bucket (gives 2) | Food (4 nutrition) that never spoils. |
| <ItemLink id="pirates_n_ships:salted_fish" /> | 1 cod or salmon, 1 dried kelp | Food (5 nutrition) that never spoils. |
| <ItemLink id="pirates_n_ships:salt_pork" /> | 1 porkchop, 1 dried kelp | Food (6 nutrition) that never spoils. |
| <ItemLink id="pirates_n_ships:lime" /> | none | Food (3 nutrition) that prevents scurvy. |
| <ItemLink id="pirates_n_ships:shackles" /> | 2 iron ingots, 1 chain | Captures weakened mobs. See [the brig](law.md). |
| <ItemLink id="pirates_n_ships:merchant_flag" /> | 1 stick, 2 white wool, 1 red dye | Flag for the flagpole. |
| <ItemLink id="pirates_n_ships:navy_flag" /> | 1 stick, 2 blue wool, 1 white dye | Flag for the flagpole. |
| <ItemLink id="pirates_n_ships:jolly_roger_flag" /> | 1 stick, 2 black wool, 1 bone | Flag for the flagpole. |
| <ItemLink id="pirates_n_ships:chart" /> | paper, leather, feather | Opens your own chart (coastlines, markers). |
| <ItemLink id="pirates_n_ships:bounty_proof" /> | none | Given for killing a target with a bounty. Hand it in for the reward. |
| <ItemLink id="pirates_n_ships:captains_whistle" /> | none | Assigns crew to stations and gives orders from a radial menu. See [Crew](crew.md). |
